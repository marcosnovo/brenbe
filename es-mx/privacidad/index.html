Privacidad y estadísticas

Esta web mide cuánta gente la visita para saber qué páginas sirven. Aquí te contamos, sin rodeos, qué se mide y qué no.

Qué se mide

Cada vez que abres una página se guarda un registro anónimo con: la página que viste y su título, la fecha y la hora, el sitio desde el que llegaste (por ejemplo Google o Pinterest) y, si el enlace la traía, la campaña (UTM); el país, el estado y la ciudad aproximados que se deducen de tu conexión; el tipo de dispositivo (celular, tableta o computadora); si parece un robot; cuánto tiempo estuviste en la página y hasta dónde bajaste; y si tocaste el botón de WhatsApp o el correo de contacto.

Qué no se hace

  • No se usan cookies.
  • No se guarda tu dirección IP.
  • No se te identifica ni se arma un perfil tuyo: para unir las páginas de una misma visita se usa un número al azar que vive solo en esa pestaña del navegador y se borra al cerrarla.
  • No se comparten estos datos con redes de publicidad.

La ciudad es aproximada

La ubicación sale de tu conexión a internet y puede no coincidir con tu casa: a veces es la ciudad de tu proveedor.

Otras herramientas

Además se puede usar Cloudflare Web Analytics (tampoco usa cookies) y Google Search Console, que le muestra a Brenda qué búsquedas llevaron a la web. Esos datos son agregados y de Google: no son de tu visita puntual. WhatsApp y el correo funcionan con sus propias políticas.

Tu decisión

Si tu navegador tiene activado "No rastrear" (Do Not Track) o el Global Privacy Control, la web no mide tu visita.

Cuánto tiempo se guardan

Los registros se borran automáticamente pasados 400 días.

Si tienes dudas, escríbele a Brenda desde la página de Contacto.
